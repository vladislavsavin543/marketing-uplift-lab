# Маркетинговый uplift-анализ

## Кому отправить предложение, чтобы получить больше покупок?

Учебный проект по **uplift-моделированию** на открытом датасете Hillstrom. Цель — сравнить клиентов, которым стоит отправить письмо с мужскими товарами, с клиентами, которым лучше ничего не отправлять.

Проект отвечает на практический вопрос: **какой клиент купит именно благодаря рассылке, а не просто потому, что и так собирался покупать?**

### Что внутри

- проверка данных и рандомизации групп;
- сравнение конверсии с письмом и без письма;
- две uplift-модели: логистическая регрессия и градиентный бустинг;
- оценка стратегии по дополнительным покупкам на фиксированном бюджете;
- понятный вывод для маркетолога.

### Данные

Используется открытый датасет [Hillstrom Mine That Data](https://www.kaggle.com/datasets/heeraldedhia/gift-sales). В проекте сравниваются две группы:

- `No E-Mail` — контроль, письмо не отправляли;
- `Mens E-Mail` — письмо с предложением мужских товаров.

Данные о покупках до кампании используются как признаки. Покупка после кампании — целевая переменная.

### Запуск

```bash
pip install -r requirements.txt
jupyter notebook notebooks/01_uplift_анализ.ipynb
```

### Ограничения

Это учебный анализ на историческом эксперименте. Результаты относятся к похожей аудитории и не гарантируют такой же эффект в новой кампании. Uplift показывает дополнительный эффект воздействия, а не общую вероятность покупки.
